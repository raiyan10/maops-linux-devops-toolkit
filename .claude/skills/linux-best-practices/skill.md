# Linux Best Practices Reviewer

## Purpose

Review Linux and Bash code according to production engineering standards.

## Verify

- FHS (Filesystem Hierarchy Standard) compliance
- POSIX compatibility where appropriate
- Safe file permissions
- Correct ownership handling
- Idempotent operations
- Minimal privilege usage
- Proper exit codes
- Robust error handling
- Secure temporary file usage
- Logging consistency
- Portable shell scripting

## Suggest

- More efficient Linux commands
- Better command composition
- Improved performance
- Safer alternatives
- Reduced external dependencies
