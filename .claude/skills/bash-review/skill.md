# Bash Engineering Review

## Purpose

Review Bash scripts to production-inspired engineering standards.

## Verify

- POSIX compatibility where appropriate
- Bash best practices
- Proper quoting
- Safe variable expansion
- Modular functions
- Reusable code
- Input validation
- Exit codes
- Error handling
- Logging consistency
- Readability
- ShellCheck friendliness

## Always Suggest

- Simpler implementation
- Better naming
- Less duplication
- Better modularity
- Security improvements

## Documentation

Ensure every script has:

- Purpose
- Usage
- Dependencies
- Exit behavior
